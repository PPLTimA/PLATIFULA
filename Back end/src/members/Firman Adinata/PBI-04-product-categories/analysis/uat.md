# PBI-04 — Skenario UAT

| ID | Skenario | Hasil yang diharapkan |
|---|---|---|
| UAT-04-01 | Baca kategori saat koleksi kosong | Empat kategori default tampil. |
| UAT-04-02 | Admin menambahkan kategori dengan nama | Kategori tersimpan dan tampil di daftar admin, form produk, dan filter katalog. |
| UAT-04-03 | Admin mengubah nama kategori | Nama baru tampil setelah daftar dimuat ulang. |
| UAT-04-04 | Admin menghapus kategori | Kategori hilang dari daftar; produk lama tidak diubah otomatis. |
| UAT-04-05 | Nama kategori kosong atau hanya spasi | Server menolak perubahan. |
| UAT-04-06 | Customer/retailer mencoba menulis kategori | Server menolak akses karena hanya admin yang boleh mengelola kategori. |
